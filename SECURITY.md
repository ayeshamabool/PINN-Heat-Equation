# 🔒 Security Policy

> **Safe Science. Clean Code. No Secrets.**
> This project is built for research — not for risk.

## 🛡️ Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest on `main` | ✅ Yes |
| Old versions | ❌ No |

We only support the newest version. Always use the latest code.

## 🚨 Reporting a Vulnerability

Found something wrong? Don't panic. Just tell us!

**How to report:**
1. Go to `Issues` tab
2. Click `New Issue`
3. Write what you found

We will fix it as soon as possible.
